# Adding layers

Find a layer and add it to the map.

| Search | Prefix | Adds | Source |
|--------|--------|------|--------|
| [WMS layers](wms.md) | `chl` | WMS layers | the federal geoportal, the cantonal services referenced by opendata.swiss |
| [WMTS layers](wmts.md) | `chw` | tiled layers, faster to display | the federal geoportal |
| [Base maps](base-maps.md) | `chb` | base maps, as vector tiles | swisstopo |

The number of results and the order of the searches can be set in the
[configuration](../configuration.md).
