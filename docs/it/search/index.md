# Ricerca

Il plugin aggiunge sei ricerche alla barra di localizzazione di QGIS. Ognuna ha
un prefisso per eseguirla da sola.

| Ricerca | Prefisso | Trova | Fonte |
|---------|----------|-------|-------|
| [Località](locations.md) | `chs` | cantoni, comuni, distretti, NPA, indirizzi, particelle, nomi della carta nazionale | geo.admin.ch |
| [Layer](layers.md) | `chl` | layer WMS | geo.admin.ch, servizi cantonali referenziati da opendata.swiss |
| [Layer WMTS](wmts.md) | `chw` | layer WMTS | geo.admin.ch |
| [Mappe di base](base-maps.md) | `chb` | mappe di base in tile vettoriali | swisstopo |
| [Oggetti](features.md) | `chf` | oggetti dei layer del geoportale | geo.admin.ch |
| [Download di file](downloads.md) | `chd` | file del catalogo dei dati | data.geo.admin.ch (STAC) |

Il numero di risultati e l'ordine delle ricerche possono essere impostati nella
[configurazione](../configuration.md).
