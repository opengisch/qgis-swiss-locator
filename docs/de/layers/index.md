# Layer hinzufügen

Finden Sie einen Layer und fügen Sie ihn zur Karte hinzu.

| Suche | Präfix | Fügt hinzu | Quelle |
|-------|--------|------------|--------|
| [WMS-Layer](wms.md) | `chl` | WMS-Layer | das Geoportal des Bundes, die auf opendata.swiss referenzierten kantonalen Dienste |
| [WMTS-Layer](wmts.md) | `chw` | gekachelte Layer, schneller angezeigt | das Geoportal des Bundes |
| [Basiskarten](base-maps.md) | `chb` | Basiskarten als Vektorkacheln | swisstopo |

Die Anzahl der Resultate und die Reihenfolge der Suchen lassen sich in der
[Konfiguration](../configuration.md) einstellen.
